# care_im_wrapper_fe

The frontend half of `care_im_wrapper`. It adds two things to CARE:

- **Notifications** (per facility) — follow the notifications the backend fires for a facility, dispatch the ones still pending, and watch delivery. `/facility/{id}/settings/notifications`
- **Notification templates** (admin) — sync the provider's approved templates, activate the ones you want, and map each template variable to a value. `/admin/notification-templates`

It is a module-federation plugin. It has no UI of its own; care_fe loads it at runtime and mounts its routes.
